# 🤖 AI & Workflow Automation – Mastery Assessment

An interactive **60-question assessment website** covering AI, RAG, LLMs, OpenAI Codex, and n8n Workflow Automation.

## ✨ Features

* 📝 60 Questions
* ⏱️ 60-Minute Timer
* 🎯 MCQ & Definition Questions
* 🔄 Previous / Next Navigation
* 📊 Automatic Scoring
* ✅ Detailed Correction Report
* 📱 Responsive UI
* 🌙 Modern Dark Theme

## 📚 Topics

* AI vs Traditional Server Architecture
* RAG Architecture
* LLMs & NLP
* OpenAI Codex
* n8n Workflow Automation

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Bootstrap 5
* AOS
* Font Awesome

## 🚀 How to Run

1. Clone or download the repository.
2. Open `index.html` in a browser.
3. Click **Start Assessment**.

No backend or database is required.
